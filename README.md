# 📚 UniNotes

---

## 🧠 Descrizione del progetto

**UniNotes** è una web app **mobile-first** per lo **scambio di appunti universitari** tra studenti del Campus di Cesena (UniBo).  
L’obiettivo è fornire un servizio utile e accessibile, che favorisca la collaborazione e la condivisione di materiali didattici in modo semplice, ordinato e gratuito.

---

## 🎯 Obiettivi

- Fornire un **servizio generico agli studenti** per la condivisione di appunti.  
- Sviluppare un’applicazione **accessibile**, **responsive** e **user-centered**.  
- Prevedere due tipologie di utenti:
  - 👑 **Admin**: crea, gestisce i corsi e modera il servizio.
  - 👤 **Utente fruitore**: può registrarsi, accedere, caricare e consultare appunti.  
- Aggiungere funzionalità “**effetto WOW**” per migliorare l’esperienza utente.

---

## 🧩 Funzionalità principali

| Ruolo | Funzionalità |
|-------|---------------|
| **Admin** | Gestione CRUD (crea, modifica, elimina, visualizza) degli appunti e degli utenti |
| **Utente** | Registrazione / login / profilo personale |
| | Upload appunti (PDF, immagini, testo) |
| | Ricerca appunti per materia, corso o keyword |
| | Download appunti |
| **Extra (WOW)** | TBD |

## 🖥️ Architettura e Tecnologie

| Livello | Tecnologie |
|----------|-------------|
| **Server (backend)** | PHP (eseguito tramite **XAMPP**) |
| **Database** | MySQL (incluso in XAMPP) |
| **Client (frontend)** | HTML5, CSS3, JavaScript (nativo), **Bootstrap 5** |
| **Design** | Mobile-first, accessibile (WCAG), responsive |
| **Ambiente di sviluppo** | XAMPP locale / Apache / phpMyAdmin |

---

## 📱 Design e Accessibilità

- L’interfaccia è progettata secondo il principio **Mobile First**, ottimizzata per schermi di smartphone.  
- I colori e i contrasti rispettano le linee guida **WCAG 2.1** per l’accessibilità.
